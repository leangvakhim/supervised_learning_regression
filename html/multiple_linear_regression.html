Multiple Linear Regression

A step-by-step guide to understanding how machines predict outcomes using multiple variables.

1 The Concept & The Student Example

Imagine you are trying to predict a student's Final Exam Score. If you only look at Hours Studied, that's Simple Linear Regression (drawing a line). But in the real world, multiple factors affect a score!

Let's predict the Exam Score ($y$) using two factors (features):

  • $x_1$: Hours Studied (0 to 10 hours)
  • $x_2$: Hours Slept the night before (0 to 10 hours)

2 The Mathematical Formula

The general formula for Multiple Linear Regression connects our target ($y$) with our features ($x_1, x_2, ... x_n$) using weights/coefficients ($\beta$).

$$ y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \epsilon $$
$\beta_0$ (Y-Intercept):
The base score a student gets if they study 0 hours and sleep 0 hours. For our example, let's say $\beta_0 = 20$.
$\beta_1$ & $\beta_2$ (Coefficients):
How much the score increases for each extra hour. Let's say $\beta_1 = 5$ (points per study hour) and $\beta_2 = 3$ (points per sleep hour).

Our Model:    Score ($y$) = 20 + 5(Study Hours) + 3(Sleep Hours)

3 Visualizing the "Regression Plane"

In Simple Linear Regression, we fit a Line through 2D points. Because we have two inputs here (Study and Sleep), we are operating in 3D space. Therefore, Multiple Linear Regression fits a flat Plane through 3D data points!

4 The Final Prediction Calculation

Based on the habits you selected in Step 3, here is how the model calculates the final exam score behind the scenes:

Calculation Step-by-Step:

1. Formula:        $y = \beta_0 + \beta_1(x_1) + \beta_2(x_2)$

2. Plug weights:   $y = 20 + 5(x_1) + 3(x_2)$

3. Plug values:    y = 20 + 5(5) + 3(7)

4. Multiply:       y = 20 + 25 + 21

Predicted Score: 66

5 Doing it in Python (Scikit-Learn)

In reality, data scientists don't calculate formulas by hand. They use Python libraries like Scikit-Learn to let the computer figure out the best weights automatically. Here is how you write the code for our exact example: 

# 1. Import the necessary tools
import pandas as pd
from sklearn.linear_model import LinearRegression

# 2. Prepare our "Student" training data
data = {
    'Study_Hours': [2, 5, 8, 3, 6],
    'Sleep_Hours': [5, 7, 8, 4, 6],
    'Exam_Score':  [45, 66, 84, 40, 68]
}
df = pd.DataFrame(data)

# 3. Separate features (X) and target (y)
X = df[['Study_Hours', 'Sleep_Hours']]
y = df['Exam_Score']

# 4. Create the Machine Learning Model
model = LinearRegression()

# 5. "Train" the model (Find the best Plane!)
model.fit(X, y)

# 6. Make a prediction for a new student
new_student = pd.DataFrame({
    'Study_Hours': [5],
    'Sleep_Hours': [7]
})
prediction = model.predict(new_student)

print(f"Predicted Score: {prediction[0]:.1f}")
# Output: Predicted Score: 67.0

Step 1 & 2: Get Tools and Data

We import pandas to manage our data tables, and LinearRegression which contains the math. Then we create a tiny dataset of 5 past students.

Step 3: Define X and y

Machine learning always separates the inputs (X, our features: Study/Sleep) from the output we want to predict (y, the target: Exam Score).

Step 4 & 5: Train the Model

Calling model.fit(X, y) is where the magic happens. The computer looks at the data points and mathematically calculates the exact placement of the 3D Regression Plane to minimize errors.

Step 6: Predict!

We create a hypothetical new student (like adjusting the sliders in Step 3) and ask the model to predict() their score based on the plane it just built.
